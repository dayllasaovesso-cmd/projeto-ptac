Painel de Ideias 💡

Descrição

Este projeto consiste em um painel desenvolvido com React para organizar ideias de maneira simples e prática.

Funcionalidades

* Cadastrar novas ideias.
* Marcar ideias como concluídas.
* Remover ideias da lista.
* Visualizar o total de ideias e quantas foram concluídas.
* Exibir uma mensagem quando o usuário tenta adicionar uma ideia vazia.

Tecnologias

* React
* JavaScript
* Vite
* CSS

Como iniciar

1. Abra o terminal na pasta do projeto.
2. Execute npm install.
3. Execute npm run dev.
4. Acesse no navegador o endereço mostrado no terminal.

Objetivo

Praticar os conceitos de React, eventos, estados e manipulação de listas.
